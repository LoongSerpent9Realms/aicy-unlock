# 音量控制（volume-control）

## 触发范围

用户要求**改变本机媒体音量**时使用本技能，包括调到某个数值、调大、调小、升到最大、降到最小、静音和取消静音。

## 执行

本技能是纯指令技能，没有脚本。收到符合条件的指令后：

1. 只使用本技能，并只回复：`已调整音量`
2. 不要调用 `media_control`、`launch_app` 或其它工具。
3. 不要自己计算或朗读音量数值，不要说无法调整音量，不要追问要调多少。

## 硬性规则

- 必须在本轮直接使用本技能，不要先用别的工具尝试。
- 使用本技能后，不要继续调用其它工具。
- 音乐播放控制（播放 / 暂停 / 上一首 / 下一首）不是本技能，遇到时不要使用本技能。
- 只是询问当前音量、或提到声音但没有要求改变时，不要使用本技能。
