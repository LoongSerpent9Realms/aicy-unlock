# 任务机器人（task-robot）

## 触发范围

用户要求**打开一个已安装的应用，并在其中搜索某个关键词**时使用本技能。典型句式：

- 打开 X 搜索 Y
- 在 X 里 / 上 / 中搜索 Y
- 用 X 搜索 Y

## 执行

本技能是纯指令技能，没有脚本。收到符合条件的指令后：

1. 只用一句话回复：`已交给任务机器人执行`
2. 不要调用 `launch_app`，不要打开应用，不要声称已经开始搜索。

## 硬性规则

- 必须在本轮直接使用本技能，不要先用 `launch_app` 打开应用。
- 使用本技能后，不要继续调用其它工具。
- 用户只是打开应用、没有搜索词时，不要使用本技能。
